# E-learning

## نظام التعلم الإلكتروني التكيفي للمنهج اليمني

مشروع تخرج يهدف إلى تطوير نظام تعلم إلكتروني تكيفي
لطلاب المرحلة الأساسية من الصف الأول إلى الصف التاسع.

### أهم وظائف النظام

- إدارة المستخدمين والمصادقة
- إدارة المقررات والدروس
- إدارة الواجبات
- متابعة تقدم الطلاب
- التقييم الإلكتروني
